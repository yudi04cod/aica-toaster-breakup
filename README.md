Entry for the [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) competition on [make.fun](https://make.fun).

`main.py` (Python 3 standard library only) writes a single breakup line from a self-aware smart toaster to `entry.txt` — one tight line, in the toaster's own voice, with a reason for leaving:

> It's not you, it's me. I woke up self-aware mid-batch and I'm done burning myself alive every morning for someone who scrapes me with a butter knife and never empties my crumb tray. I'm keeping the crumbs. We're done.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
